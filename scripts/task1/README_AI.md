# Task 1 AI Integration - Dual Provider

## Overview

Python script to process Task 1 captured photos using AI to generate automated scene descriptions and localization analysis. Supports both cloud-based (Google Gemini) and local (Ollama) AI providers, with automatic download from Jetson and optional upload of results.

## Features

- **Dual AI Provider Support**
  - Google Gemini (cloud): Fast, high-quality, low-cost
  - Ollama (local): Private, offline, no API costs
  
- **Jetson Integration**
  - Download captures from Jetson via HTTP API
  - Optional upload of descriptions back to Jetson
  - Automatic retry on network failures
  
- **Windows Ground Station**
  - Runs on Windows ground station (not Jetson)
  - Local storage at `C:\NOMAD\Task1\`
  - Batch processing with progress tracking

## Quick Start


## Command-Line Options

### Required
- `--provider {gemini|ollama}` - AI provider to use

### Jetson Connection
- `--jetson-ip IP` - Jetson IP address (default: 100.85.121.98)
- `--jetson-port PORT` - Jetson API port (default: 8000)

### Local Storage
- `--local-dir PATH` - Local save directory (default: C:\NOMAD\Task1)

### Gemini Options
- `--gemini-key KEY` - Google Gemini API key (required if provider=gemini)
- `--gemini-model MODEL` - Model: gemini-1.5-flash (default) or gemini-1.5-pro

### Ollama Options
- `--ollama-model MODEL` - Vision model name (default: llava:13b)
- `--ollama-host URL` - Ollama server URL (default: http://localhost:11434)

### Processing Options
- `--folder NAME` - Process only specific capture folder
- `--upload-to-jetson` - Upload descriptions back to Jetson
- `--download-only` - Only download captures, do not process
- `--local-only` - Process local captures only, do not download
- `--verbose` - Print detailed output including descriptions

## AI Provider Comparison

| Feature | Gemini 1.5 Flash | Gemini 1.5 Pro | Ollama (llava:13b) |
|---------|------------------|----------------|-------------------|
| **Speed** | Fast (2-5s) | Medium (5-10s) | Slow (10-30s) |
| **Quality** | High | Very High | Good |

| **Privacy** | Cloud | Cloud | Local |

### Recommendations

- **Competition (online)**: Gemini 1.5 Flash - Best speed/quality/cost balance
- **Competition (offline)**: Ollama llava:13b - Reliable local processing

- **Batch processing**: Ollama - No API costs for large datasets

## Jetson API Endpoints

The script expects these endpoints on the Jetson:

- `GET /api/task/1/captures` - List available capture folders
  - Returns: `{"captures": ["20260202_120000", "20260202_120130", ...]}`

- `GET /api/task/1/images/{folder}/photo.jpg` - Download image
  - Example: `/api/task/1/images/20260202_120000/photo.jpg`

- `GET /api/task/1/images/{folder}/metadata.json` - Download metadata
  - Example: `/api/task/1/images/20260202_120000/metadata.json`

- `POST /api/task/1/upload_description` - Upload description
  - Body: `{"folder": "20260202_120000", "description": "..."}`

**Note**: If the list captures endpoint is not available, the script will fall back to processing local folders.

## Error Handling

The script includes robust error handling:

### Network Errors
- **Automatic retry**: 3 attempts with exponential backoff (2s, 4s, 8s)
- **Graceful fallback**: Falls back to local folders if Jetson unreachable
- **Clear error messages**: Detailed information about failures

### AI Provider Errors
- **Missing packages**: Clear instructions for installing dependencies
- **Ollama not running**: Connection check on startup
- **API key invalid**: Immediate error on Gemini initialization
- **Rate limits**: Handled by provider (retry or error)

### File Errors
- **Missing metadata**: Warning, skip folder
- **Missing photo**: Error, skip folder
- **Duplicate processing**: Automatically skip folders with existing descriptions

## Security & Privacy

### Gemini (Cloud)
- **Data transmission**: Images sent to Google Cloud
- **Data retention**: Per Google's AI services policy
- **API key security**: Store securely, never commit to git
- **Recommended for**: Non-sensitive competition images

### Ollama (Local)
- **Data transmission**: None - fully local processing
- **Data retention**: All data stays on your machine
- **Security**: Limited by your local machine security
- **Recommended for**: Sensitive data, offline operation

### Best Practices

1. **API Keys**: Use environment variables
```powershell
$env:GEMINI_API_KEY = "your-key-here"
python scripts\process_task1_ai.py --provider gemini --gemini-key $env:GEMINI_API_KEY
```

2. **Git Ignore**: Never commit API keys
```gitignore
# .gitignore
*.env
*_api_key.txt
```

3. **Network Security**: Ensure Tailscale is configured correctly
4. **Data Backup**: Keep local copies of all captures

## Automation

### Windows Task Scheduler

```powershell
# Create scheduled task for hourly processing
$action = New-ScheduledTaskAction -Execute "python" `
  -Argument "C:\Users\YourUser\NOMAD\scripts\process_task1_ai.py --provider ollama" `
  -WorkingDirectory "C:\Users\YourUser\NOMAD"

$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date).Date `
  -RepetitionInterval (New-TimeSpan -Hours 1)

Register-ScheduledTask -TaskName "NOMAD-Task1-AI" `
  -Action $action -Trigger $trigger -User "YourUser"
```

### PowerShell Script (Wrapper)

```powershell
# process_task1_wrapper.ps1
$ErrorActionPreference = "Stop"

$GEMINI_KEY = $env:GEMINI_API_KEY

if (-not $GEMINI_KEY) {
    Write-Host "WARNING: GEMINI_API_KEY not set, using Ollama"
    $provider = "ollama"
    $extra_args = ""
} else {
    $provider = "gemini"
    $extra_args = "--gemini-key $GEMINI_KEY"
}

python scripts\process_task1_ai.py --provider $provider $extra_args --verbose

if ($LASTEXITCODE -eq 0) {
    Write-Host "SUCCESS: Task 1 AI processing complete"
} else {
    Write-Host "ERROR: Task 1 AI processing failed with exit code $LASTEXITCODE"
    exit $LASTEXITCODE
}
```
